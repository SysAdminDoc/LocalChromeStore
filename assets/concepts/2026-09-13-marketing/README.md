# LocalChromeStore marketing archive

This folder keeps the complete 2026-09-13 identity and README image pass.

- `original/` contains the README, roadmap, changelog, logo, and banner as found before the pass.
- `concept-01` through `concept-05` preserve all five identity directions. Concept 02 became the production mark.
- `captures/` contains the selected app views plus the earlier capture with the opaque icon edge.
- `compositing/` contains base renders, intermediate composites, final layouts, and the README-width preview.
- `legacy-screenshots/` preserves earlier application screenshots that were previously stored in the ignored screenshots folder.

Production files live in `../../brand/`, `../../marketing/`, and `../../screenshots/`.
